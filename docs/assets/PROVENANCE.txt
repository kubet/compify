# Documentation media

`demo-video.mp4` is a first-party Compify browser-editor recording supplied by
the project maintainer. `legacy-editor-demo.webp` is a static README thumbnail
captured from the recording at 12 seconds with FFmpeg:

```bash
ffmpeg -ss 12 -i docs/assets/demo-video.mp4 -frames:v 1 \
  docs/assets/legacy-editor-demo.webp
```

The full README animation is derived from the same recording:

```bash
ffmpeg -i docs/assets/demo-video.mp4 \
  -vf "fps=8,scale=720:-1:flags=lanczos,palettegen=max_colors=128:stats_mode=diff" \
  /tmp/compify-palette.png
ffmpeg -i docs/assets/demo-video.mp4 -i /tmp/compify-palette.png \
  -lavfi "fps=8,scale=720:-1:flags=lanczos[x];[x][1:v]paletteuse=dither=bayer:bayer_scale=5:diff_mode=rectangle" \
  docs/assets/demo.gif
```
