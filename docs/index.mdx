a Bun-powered CLI, and an MCP server for coding agents.

## The workflow

<Steps>
### Build

Create or import a React component in the live editor. Compify supports multiple
files, dependencies, themes, and sandboxed previews.

### Publish

Choose visibility and a stable `@owner/component` address. Public components
receive a preview page and registry endpoint.

### Install

Pull the component with the Compify CLI, the shadcn CLI, or an MCP-enabled coding
agent. Source files stay in your project and remain editable.
</Steps>

<Callout title="Self-host friendly">
All browser-facing API, site, and editor-asset origins are configurable. The
included Compose stack runs migrations and provisions the required object-storage
buckets automatically.
</Callout>
