## Requirements

- [Bun 1.3.9](https://bun.sh/)
- Git
- A React Storybook repository for the translation workflow
- Docker with Compose only if you want to run the self-hosting baseline

## Build the current source

The Storybook commands and addon described in these docs are available from the
repository source/release candidate. This documentation does not imply package
registry availability or a managed hosted service.

```bash
git clone https://github.com/kubet/compify.git
cd compify/packages/cli
bun install --frozen-lockfile
bun run build
bun link
compify --help
```

## Inspect before translating

From a React Storybook project:

```bash
compify storybook inspect src/components/Button.stories.tsx
compify storybook export src/components/Button.stories.tsx \
  --output .compify/button.registry-item.json
```

Inspection is static: it parses source without importing or executing the story
module. Support is intentionally constrained; read [Storybook translation](/docs/storybook)
before relying on it in automation.
