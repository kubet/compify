## Requirements

- [Bun 1.3.9](https://bun.sh/) for repository and CLI workflows
- Git
- Docker with Compose for the recommended self-hosted deployment

## Use the hosted service

Open [the editor](https://compify.app/create), create a component, and publish it.
Install the CLI with Bun:

```bash
bun add --global @compify/cli
compify login
compify add @owner/component
```

The CLI writes source files into the current project and records them in
`components.json`. See the [CLI reference](/docs/cli) for non-interactive and
machine-readable workflows.

## Run a self-hosted stack

```bash
cp deploy/self-host.env.example .env
# Replace every placeholder secret and set your public origins.
docker compose up -d --build
docker compose ps
```

The web application defaults to [http://localhost:3000](http://localhost:3000) and the API to
[http://localhost:3009](http://localhost:3009). Confirm both deployment probes:

```bash
curl --fail http://localhost:3009/health
curl --fail http://localhost:3009/ready
```

Continue with the [self-hosting guide](/docs/self-hosting) before exposing the
stack to the internet.
